# Code of Conduct

**Last updated:** 2026-09-15

Umbrella Wallet is an independent, source-available project. Collaboration happens through issues,
security advisories, and (when invited) pull requests — not through public forks or rebrands.

## Our standards

**Expected**

- Assume good faith; keep technical disagreement technical.
- Never ask for, paste, or demand seed phrases, private keys, passwords, or wallet files.
- Report security issues **privately** ([SECURITY.md](SECURITY.md)).
- Respect the [LICENSE](LICENSE) and [TRADEMARK_POLICY.md](TRADEMARK_POLICY.md).
- Prefer clear reproduction steps over blame.

**Unacceptable**

- Harassment, hate speech, doxxing, or threats.
- Social-engineering users into revealing keys or installing unsigned malware.
- Publishing vulnerability details before coordinated disclosure.
- Spamming issues with marketing, phishing links, or off-topic promotion.
- Impersonating maintainers, official releases, or support channels.

## Scope

This applies in GitHub issues/PRs/discussions, security advisories, and official community channels
listed in [CONTACT.md](CONTACT.md) (including Telegram).

## Enforcement

Maintainers may warn, edit, lock, or ban. Security-sensitive abuse may be reported to the host
platform. Decisions aim to protect users first.

## Reporting

- **Conduct / abuse:** open a private note via [CONTACT.md](CONTACT.md) or Telegram admins.
- **Vulnerabilities:** [GitHub Security Advisories](https://github.com/kiurakku/UmbrellaWallet/security/advisories/new) only.

Do not send seeds or keys when reporting anything.
