# Archived: legacy web product docs (as of 2026-07)

**These documents do not describe the shipped product.** They describe an earlier
React / NestJS / Prisma / P2P web application (deployed to Vercel / Fly.io) that has been
**discontinued**. Umbrella is now a **desktop-only** wallet (.NET 8 + Avalonia, Windows & Linux;
Android planned) with **no web app and no backend server**.

They are kept only as historical record. Do **not** follow them to build, deploy, or reason about
the current wallet — anything here about IndexedDB, JWT, KYC, an API/backend, Prisma, Docker,
Vercel/Fly.io, or a P2P web marketplace is obsolete.
